# Projeto A Escrava Isaura - Aplicação de Conhecimentos em HTML

## Descrição

Este projeto é uma página web dedicada à telenovela brasileira "A Escrava Isaura", onde aplico meus conhecimentos em HTML para criar páginas informativas sobre os personagens principais. O objetivo é demonstrar o uso de elementos HTML5 de forma estruturada e semântica, incluindo navegação, conteúdo multimídia e links.

## Estrutura do Projeto

- `index.html`: Página inicial do projeto, com uma introdução à telenovela e links para as páginas dos personagens.
- `isaura.html`: Página dedicada ao personagem Isaura, incluindo biografia, imagens e áudio.
- `leoncio.html`: Página dedicada ao personagem Leôncio, com informações sobre seu papel na história.
- `miguel.html`: Página dedicada ao personagem Miguel, destacando sua relação com Isaura.
- `audio/`: Pasta contendo arquivos de áudio relacionados à telenovela.
- `fotos/`: Pasta com imagens dos personagens e cenas da novela.

## Tecnologias Utilizadas

- **HTML5**: Linguagem de marcação utilizada para estruturar o conteúdo das páginas, aplicando elementos semânticos como `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`, além de `<img>`, `<audio>`, `<a>`, listas (`<ul>`, `<ol>`), tabelas (`<table>`), e formulários básicos se aplicável.

## Conhecimentos em HTML Aplicados

Neste projeto, demonstro os seguintes conceitos de HTML:

- **Estrutura Semântica**: Uso de tags semânticas para melhorar a acessibilidade e SEO, como `<header>` para cabeçalhos, `<nav>` para navegação, `<main>` para conteúdo principal, e `<footer>` para rodapés.
- **Links e Navegação**: Links internos entre páginas (`<a href="isaura.html">`) e externos para mais informações sobre a novela.
- **Multimídia**: Incorporação de imagens (`<img>`) da pasta `fotos/` e áudio (`<audio>`) da pasta `audio/` para enriquecer o conteúdo.
- **Listas e Tabelas**: Organização de informações usando listas não ordenadas/ordenadas e tabelas para dados estruturados.
- **Formatação de Texto**: Uso de headings (`<h1>` a `<h6>`), parágrafos (`<p>`), ênfase (`<strong>`, `<em>`), e quebras de linha (`<br>`).
- **Acessibilidade**: Atributos como `alt` em imagens para descrever o conteúdo alternativo.

## Como Visualizar o Projeto

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (como Chrome, Firefox ou Safari).
3. Navegue pelas páginas usando os links fornecidos.
